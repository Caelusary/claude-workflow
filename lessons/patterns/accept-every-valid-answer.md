**Principle:** When a problem has several correct answers, the app checks validity and shows the full set. It never marks the user wrong against whichever answer a tie-break rule produced.
**Why it recurs:** The checker is written against the author's one worked example.
**Check:** For each exercise or input, can there be more than one right answer? If so, does the checker test validity, and can the user see the alternatives?
