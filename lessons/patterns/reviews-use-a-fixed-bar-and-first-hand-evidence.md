**Principle:** Before auditing, write down the checklist and the severity bar, run it over the whole artifact once, rank findings, and report re-checks only as a diff against that list. A claim, citation or 'not done' status counts as verified only when the exact supporting text or code window has been read first-hand.
**Why it recurs:** Open-ended re-reviews drift and surface new subjective issues each pass; inferred status from one search hit or a title page feels like verification and is not.
**Check:** Is there a written checklist and severity bar? For each reported gap or citation, can I point to the exact code window or sentence I read? Does the second pass report only regressions and checklist misses?
