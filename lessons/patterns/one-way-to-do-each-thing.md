**Principle:** Keep the primary destinations always visible, put the rest behind one obvious menu, never show the same control twice on a screen, make similar controls behave identically, and give every screen exactly one way back that always looks the same.
**Why it recurs:** Features get added screen by screen, each adding its own control, so duplicates and near-duplicates accumulate in different styles.
**Check:** Count the taps to the top tasks. Is any control duplicated on the same screen, or styled differently from its siblings? How many controls go back on each detail page?
